### Featured Work

**NeoVani — Real-Time Speech-to-Speech Translation**
ASR→NMT→TTS pipeline across 5 Indian languages. Fine-tuned NVIDIA NeMo Conformer-CTC and FastConformer models with a custom akshara-seeded 10k-unigram SentencePiece tokenizer.
- 9.10% WER / 2.83% CER, RTF 0.025 (39× real-time), ~1.2s end-to-end latency across 2,464 samples
- BLEU up to 19.04 on a 1.19M-pair parallel corpus
- Ported from Tkinter to a NiceGUI/FastAPI web app (persistent subprocess workers, line-delimited JSON IPC, browser-side 16kHz WAV capture, ~45ms web overhead)
- Docker-packaged on an NVIDIA PyTorch base image

**rag3gpp — RAG Chatbot over 3GPP Telecom Standards**
Built for a Mavenir Systems GET submission. Hybrid BM25 + dense retrieval with cross-encoder reranking, CRAG-style relevance filtering, and propose-critique-abstain generation, evaluated with RAGAS on a multi-service Docker Compose stack.

**AIScout — Local-First Research Intelligence Agent**
Runs fully local on Ollama (qwen3.5:9b + phi4-mini) with BAAI/bge-base-en-v1.5 embeddings. Propose-then-critic architecture validated against a 32-test faithfulness evaluation suite.
